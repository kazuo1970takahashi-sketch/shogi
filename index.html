はじめての方へ（他のクラブ・支部の方）

このアプリは、沼津支部が自分たちの月例会のために作り、毎月の運営で実際に使っているものです。他のクラブ・支部の方も、そのまま自由にお使いいただけます。登録も費用も要りません。上の「大会運営アプリを開く」からすぐ試せます。

今できること

  • 大会名・主催者・会場・持ち時間・賞金額を自分のクラブのものに変えて、受付 → 組み合わせ（スイス式）→ 勝敗入力 → 順位 → 対戦成績・大会報告書の印刷 / PDF保存まで、一通り運営できます
  • 自分のクラブの設定を「既定」として覚えさせられます。「最終結果」タブの「⚙ クラブの既定（全リセット後の初期値）を保存する」→「💾 この設定をクラブの既定として保存」を一度押しておけば、翌月に「大会データを全リセット」しても、大会名・主催者・会場・持ち時間・賞金額・クラス構成・回戦数はそのまま残ります
  • クラスは A・B・C… と追加・改名できます（回戦数はクラスごとに 3〜7 で設定できます）
  • 人数が奇数のクラスも、そのまま始められます。「このクラスを部分開始」で来ている方から始めれば、組み合わせに入らなかった方は待機として画面に明示され（不戦勝にはなりません）、次の回戦で戻ります
  • データは端末のブラウザ内に保存されます。インターネットが無い会場でも動きます（ただし初回だけは、大会前に一度オンラインで開いて10秒ほど待ってください。そのときにアプリ本体が端末へ保存され、以後オフラインで起動できるようになります。手順は上の「📱 ホーム画面に追加する方法」に載っています。保存に失敗しても画面上はふつうに開けてしまうので、大会前に機内モード（またはWi-Fiとモバイル通信を切った状態）で一度アプリを開いて、いつもの画面が出ることを必ず確かめてください。出なければ、オンラインに戻してもう一度開き直します）

今できないこと（隠さずに書いています）

  • 参加費の金額は変えられません。沼津支部の金額で固定です。金額が異なるクラブでは、集金額の自動計算は参考値としてお使いください
  • クラウド送信・名簿共有・📡 参加者向けライブ配信は、現在この1クラブ専用です。ほかのクラブのアカウントを作る仕組みが、まだアプリにありません（沼津支部のアカウントに紐づいています。ログイン自体はできますが、送信・取得・配信は「送信先クラブを一意に特定できません」等で止まります）。端末内での運営と、印刷・PDF出力までが使える範囲とお考えください。なお 📱 スマホ星取表（同じ端末の別タブに全画面表示・会場のサブ画面向け）はインターネット不要ですので、どのクラブでもそのままお使いいただけます
  • 画面の一部に「沼津支部」の表示が残ります（画面上部の見出し、会員名簿タブ、成績表・報告書の会員区分など）。会員区分の呼び名（支部員／支部員以外）も変えられません
  • クラブの既定に保存できるのは、この端末のブラウザの中だけです。端末を替えると設定し直しになります（☰メニューの「バックアップ」で取ったJSONに同梱されるので、それを新しい端末で読み込む方法もあります）
  • A・Bクラスは削除できません。アプリの既定クラスのため、1クラスだけで運営したい場合も空の B が残ります（改名はできます）
  • 大会名・主催者・会場・賞金額を空欄のままにすると、沼津支部の既定値が入ります。必ず自分のクラブの値を入れてください（FAX・事務局名・会計提出文の3つだけは空欄のまま使えます）

保証していないこと

沼津支部の有志が作って公開しているものです。動作の保証、データの保持、大会当日のサポートはできません。データは各自の端末のブラウザ内にあります。端末の故障・紛失に備えるには、☰メニューの「バックアップ」でJSONファイルの控えを取ってください。ただし、保存先は既定でその端末のダウンロードフォルダです。端末ごと失うと控えも一緒に失われるので、取ったJSONを別の端末・USBメモリ・クラウドストレージ（メール添付でも可）へコピーしてはじめて備えになります。

試すときのおすすめ

  1. 本番の前に一度、練習で通してみてください。架空の名前を10人ほど入れて、受付から報告書の出力までやってみると、当日の見通しが立ちます
  2. 会員名簿を Excel などでお持ちなら、「📥 まとめて登録（エクセルから貼り付け）」で参加者としてまとめて受付 → 「📋 参加者を名簿に反映」で会員名簿に登録、が最短です（「📥 まとめて登録」だけでは会員名簿には入りません）
  3. 大会名・会場などを自分のクラブのものに入れ終えたら、「最終結果」タブの「💾 この設定をクラブの既定として保存」を一度押しておいてください。翌月からの入れ直しが要らなくなります
  4. 練習が済んだら、☰メニューの「大会データを全リセット」でまっさらにしてから本番に臨んでください

当日の流れ

※ ここから下は沼津支部の当日の運営手順です。進め方は他のクラブでもそのまま参考にしていただけますが、☁ ログイン・名簿の取得・クラウドへの送信・📡 ライブ配信は沼津支部のアカウントが必要で、他のクラブ・支部の方は現在お使いいただけません。その部分は読み飛ばしてください。

1
受付【名簿からタップで時間短縮】

常連の参加者は名簿から名前をタップするだけで受付できる。役割分担は以下。

  • 受付係：対局カード記入依頼・集金を担当
  • 登録係：「📋 名簿から受付（過去参加者から選ぶ）」で①クラスを選ぶ→②名前をタップ、で受付（漢字・ふりがな検索 / 50音で絞り込み可・会費区分も引き継がれる）。名簿にない新規の方のみ「＋ 名簿にない新規の方（手入力）」から入力。
  • まとめて登録：事前に参加者リスト（Excel など）を集めてある大会は、大会開始前に「📥 まとめて登録（エクセルから貼り付け）」へ「氏名・ふりがな・クラス」を貼り付け→プレビュー→確定で、受付をまとめて済ませられる。エラー行（同名・空の氏名・クラス名不明）は自動で除外され、理由がプレビューに表示される。「区分の既定」（支部員／一般）は全行に適用。登録した参加者は会員名簿には載らない（通常の大会では「📋 参加者を名簿に反映」で名簿に新規追加・🎪 ゲスト大会でもそのまま使える）。
クラウドを使う日は先に「会員名簿」タブからログインしておく（送信・ライブ配信・名簿取得に必要）。初めて使う端末で名簿が空のときは「会員名簿」タブの「☁ クラウドから取得」で共有名簿を取り込める。
奇数になった場合は運営者が参加して偶数にしてから、対局管理タブの「〇クラス全員で1局目を開始」を押す（来た人から始めるなら「このクラスを部分開始」）
2
1回戦対局中に情報を整備

1回戦の対局中に余裕を持って以下を行う。

  • 氏名・ふりがな・会費区分の直しは、参加者カードの「⋯ 編集」から（会費は自動計算される）
  • 集金額とアプリの計算結果を突き合わせ
  • 新規参加者はふりがなを入れておくと次回以降の検索が楽になる
3
2・3回戦【比較的スムーズ】

対局カードを回収後、勝敗をアプリに登録して「確定して次へ」を押すと次回戦のペアリングが自動生成される。生成された手合いを対局カードに記入する。

組み合わせを変えたい場合は「組み合わせを再生成」ボタンを押す。特定の対局のみ変えたい場合は「対戦相手変更」ボタンを押す
4
4回戦終了・表彰

最後の勝敗をアプリに入力したら、「最終結果」タブに順位が即座に表示される。この画面を見ながらそのまま表彰式を行うことで転記の待ち時間をゼロにできる。対局表への転記や印刷/PDF保存は表彰後に余裕を持って行う。

5
終了後（クラウド送信・報告書・名簿反映）
  • 「☁ クラウドへ送信」で結果をクラウドに残す・共有する（ログイン時）
  • 「最終結果」タブ下部の報告書情報欄に開催日・時間・担当役員・申し送り事項を入力し、「報告書を印刷 / PDF保存」ボタンを押す。印刷ダイアログで「PDFとして保存」を選ぶ
  • 「📋 参加者を名簿に反映」で今日の参加者を会員名簿へ反映する
「📋 参加者を名簿に反映」（ヘッダの緑ボタン）とは
いつ押す：受付が落ち着いたら1回（終了時は「☁ クラウドへ送信」でも確認が出ます）。
何が起きる：今日の参加者が会員名簿に載り、参加記録が付く（名簿から消えるものはありません）。押すと「新規追加 ○人・参加記録 ○人」と結果が表示されます。
間違えても：何度押しても結果は同じで安全（2回目は「反映済みです（変更なし）」と出ます）。当日編集したふりがなが名簿と違うときだけ確認が出ます。
ゲスト大会では：自動で止まります（理由が表示され、名簿は変わりません）。

参加者・会場に成績を見せる（任意）

  • 📱 スマホ星取表（ヘッダのボタン）：同じ端末の別タブで星取表を全画面表示。会場ディスプレイやサブ画面向け（ネット不要・自動更新）。
  • 📡 参加者向けライブ配信：参加者が自分のスマホで順位・星取を見られるように公開する。「最終結果」タブ先頭の配信欄で表示名（既定は「姓＋番号のみ」）を選んで開始し、QRを印刷して会場に掲示する。終わったら「⏹ 配信を停止」。
ライブ配信はインターネット公開です。掲示物には「氏名・成績を公開する」旨を必ず明記する。フルネーム表示は告知・同意の運用を決めた場合のみ。

スイス式トーナメントのルール

ペアリング

  • 1回戦：順番に組み合わせ
  • 2回戦以降：同じ勝ち数の人同士で対戦
  • すでに対戦した相手とは再戦しない
  • 同星で組めない場合は隣の勝ち数の人と対戦
  • 奇数になった場合は運営者が参加して偶数を保つ

順位決定（優先順位順）

  1. A（勝ち数）が多い人が上位
  2. B（SOS）：対戦相手の最終勝ち数合計が多い人が上位
  3. C（SODOS）：自分が勝った相手の最終勝ち数合計が多い人が上位
  4. 直接対決：対戦がある場合は勝者が上位
  5. くじ引き：それでも同率の場合

持ち時間

大会により異なります（当日の報告書に記載）。持ち時間は「切れ負け」または「秒読み（切れたら一手N秒）」から設定します。

注意事項

※ ☁ クラウドと📡 ライブ配信に触れている項目は、沼津支部のアカウントをお持ちの場合の説明です（他のクラブ・支部の方は現在お使いいただけません）。それ以外の項目はどのクラブにも当てはまります。

  • データは入力のたびに端末のブラウザ内へ自動保存されます（操作は不要）。誤ってブラウザを閉じても消えません。
  • ただし端末の故障・紛失には自動保存では備えられません。端末事故から復元できるのは ☰メニューの「バックアップ」（JSONファイルの保存／復元）だけです。節目で控えを取っておくと安心です。
  • 「☁ クラウドへ送信」は結果の共有・控えになります（ログインとネット接続が必要・任意）。送信した大会は「大会履歴」タブの「☁ クラウドの過去大会」で星取表つきで閲覧できます。バックアップの代わりにはなりません。
  • 会員名簿（過去参加者の氏名・参加履歴）も同じ端末内に保存されます。「会員名簿」タブで確認でき、「☁ クラウドから取得」で共有名簿を取り込めます。
  • 📡 ライブ配信は氏名・成績のインターネット公開です。表示名は既定で「姓＋番号のみ」。掲示物に公開する旨を明記してください。
  • 名簿にない参加者が大半の別大会（オープン大会など）は「🎪 ゲスト大会」で運営できます。参加者登録タブの「⚙ 大会の設定」→「大会の種類」で選ぶと、その大会の参加者・結果は会員名簿に記録されません（名簿からの受付・ライブ配信・報告書はそのまま使えます・開始後は変更不可）。
