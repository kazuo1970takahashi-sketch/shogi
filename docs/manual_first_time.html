第0章はじめに — 安心して使うための3か条

このアプリは「壊さないように恐る恐る触る」ものではありません。次の3つだけ覚えておけば、安心して触れます。

  1. 入力は全部、自動で保存されます。ボタンを押すたびにこの端末の中に保存されるので、「保存し忘れて消えた」は起きません。ブラウザを閉じてしまっても、開き直せば続きから再開できます。
  2. 危ない操作の前には、必ず確認画面が出ます。いきなりデータが消えるボタンはありません。確認の文章を読んでから「はい」を押せば大丈夫です。
  3. 会員名簿と過去の大会履歴は、リセットしても消えません。「大会データを全リセット」をしても、会員名簿（支部マスタ）と大会履歴は必ず残る設計です。

練習まず「練習」から始めてください（本番の前に）

このアプリは自宅で何回でも練習できます。架空の名前（山田 太郎、鈴木 一郎…など何でも）で参加者を登録して、1人で2役をやりながら4回戦まで通してみてください。ぶっつけ本番で触るより、これが一番の近道です。このマニュアルの画面写真も、その練習と同じ手順で撮ったものです。

練習のあいだ、押してはいけないボタンは2つだけ。
① 画面上部の緑のボタン 📋 参加者を名簿に反映 — 架空の名前が本物の会員名簿に入ってしまいます
② 最終結果タブの ☁ クラウドへ送信（任意） — 練習結果がみんなに共有されてしまいます
この2つ以外は、どのボタンを押しても大丈夫です。

練習が終わったら、☰メニューの大会データを全リセットで練習データを消します（第2章の手順と同じ）。会員名簿と大会履歴は消えません。もし練習中に「現在の大会を履歴へ保存」を押した場合だけ、大会履歴タブでその練習分を🗑で削除しておいてください。

最後の章に「合格チェックリスト」があります。全部にチェックが付けば、本番も一人で運営できます。

第1章アプリを開く・画面の見かた

  1. ブラウザ（Safari や Chrome）で次のアドレスを開きます。
    https://kazuo1970takahashi-sketch.github.io/shogi/
    スマホでもタブレットでもパソコンでも動きます。よく使う端末では、ブックマーク（お気に入り）か「ホーム画面に追加」をしておくと次から一発で開けます。
  2. 画面の上に5つのタブが並んでいます。左から順に使っていくのが基本です。
タブ何をする場所か
参加者登録当日の受付。参加者の名前を登録する
対局管理組み合わせを作り、勝敗を入力する（当日いちばん使う）
最終結果順位表・印刷・報告書
会員名簿会員の元データ。当日は基本さわらない
大会履歴過去の大会の記録。見ても今の大会には影響しない
⚠ 赤い帯「この端末ではデータが保存されません」が出たら：ブラウザがシークレットモード（プライベートモード）になっています。そのままだと閉じた瞬間にデータが消えるので、通常モードのブラウザで開き直してください。

第2章大会を始める前の準備（毎回必ず・順番どおり）

アプリを開いたとき、前回の大会のデータが画面に残っているはずです。これを正しい順番で片付けてから、今日の受付を始めます。この順番だけは守ってください。とくに「全リセットを最初にやってしまう」と前回の記録が消えます。

  1. 「大会履歴」タブ → 現在の大会を履歴へ保存 を押す。
    前回の大会がこの端末の記録として残ります。これは自動ではやってくれません。忘れると次のリセットで前回の対局データが消えます。
  2. 右上の ☰ → バックアップ → バックアップを保存（ダウンロード）。
    ファイル（shogi_backup_日付_時刻.json）が端末に保存されます。万一のときの保険です。
  3. 同じ ☰ メニューの 大会データを全リセット を押し、確認画面で「はい」。
    これで前回の参加者・組み合わせ・勝敗が消えて、今日の大会をまっさらな状態から始められます。
  4. 「会員名簿」タブを開いて、人数がいつも通りあることを目で確認。これで準備完了です。
☰の中の「大会進行データをリセット」は使いません。あれは「同じ日に組み合わせだけやり直す」ための特殊なボタンです。月例会の準備では必ず「大会データを全リセット」の方を使ってください（こちらでないと、新しい大会として正しく記録されず、クラウド上で前回の大会に上書きされる事故につながります）。
この章の手順は、前回の大会の直後（片付けのとき）にやっても、当日の朝にやっても構いません。「履歴へ保存 → バックアップ → 全リセット → 名簿確認」の順番だけがルールです。

第3章受付 — 参加者を登録する

「参加者登録」タブで、来た人を登録していきます。登録のしかたは3通りありますが、まずは手入力を覚えれば十分です。

手入力で1人ずつ登録する

  1. 「＋ 名簿にない新規の方（手入力）」の欄に、氏名とふりがなを入れる
  2. クラス（Aクラス／Bクラス）を選ぶ
  3. 追加 を押す。「〇〇さん（Aクラス）を登録しました」と出れば成功
他の2通り：📋 名簿から受付（過去参加者から選ぶ）＝いつものメンバーを名簿から選ぶだけ。📥 まとめて登録（エクセルから貼り付け）＝一覧表を一度に貼り付け。どちらも画面の案内どおりに進めば使えます。

登録した人の一覧を確認する

登録すると、クラスごとの一覧に並びます。各行で「支部員／支部員以外」「一般／中学生以下／女性」を選べて、参加費が自動計算されます。名前の右の ⋯ 編集 から名前の修正や取り消しができます（第7章）。

受付が一段落したら、一番下の 登録内容を確認して対局管理へ を押して次へ進みます。

第4章対局を始める（偶数のとき・奇数のとき）

「対局管理」タブでは、クラスごとに独立して対局を進めます。Aクラスが2回戦の途中でも、Bクラスはまだ1回戦、という進み方で構いません。

人数が偶数のクラス → ワンタッチで開始

〇クラス全員で1局目を開始 を押すだけです。組み合わせは自動で作られます。

人数が奇数のクラス → 「部分開始」で始める

奇数のクラスでは「全員で開始」ボタンが表示されません（上の画像の右側）。次の手順で始めます。

  1. このクラスを部分開始（未割当者を表示） を押す
  2. 未手合いをまとめて1局目作成 を押す
  3. 確認画面に「誰と誰が当たるか」「誰が待機になるか」が出るので、「はい」を押す
この「部分開始」は、全員そろう前に、来た人から先に始めたいときにも使えます。後から来た人は、同じ画面でチェックを付けて「選択した参加者で1局目を追加作成」で追加すればOK。すでに始まっている対局には影響しません。

第5章勝敗を入力して回戦を進める

ここが当日の基本動作です。「勝った人のボタンを押す → 全卓終わったら確定」の繰り返しだけで、4回戦まで進みます。

  1. 対局が終わったら、その卓の勝った人の名前ボタンを押す。
  2. 全部の卓を入力すると、緑の 〇回戦 確定して次へ が押せるようになる。押すと次の回戦の組み合わせが自動で作られる。なお、勝敗を入れた対局は、次の対局を操作した時点で「終わった対局」の中に畳まれます（数字が入力済みの数。タップで開いて見直せます）。
  3. これを4回戦まで繰り返す。組み合わせは「同じ勝数どうし・再戦なし」を基本に自動で組まれます。

第6章大会が終わったら（結果・印刷・片付け）

4回戦がすべて終わると、「最終結果」タブに順位表ができています。

印刷と報告書

  1. 対戦成績を印刷 / PDF保存 — 星取表つきの成績表を印刷（またはPDF保存）できます。
  2. 「大会報告書」の欄を埋めて 報告書を印刷 / PDF保存 — 連盟に出す報告書がそのまま出せます。
    ⚠ 「開催日」の欄は「アプリを開いた日」が自動で入ります。前日に準備で開いた場合などは日付がずれていることがあるので、印刷前に開催日を必ず目で確認してください。

片付け（3つ押して終わり）

  1. 画面上部の緑のボタン 📋 参加者を名簿に反映 — 今日の参加者・成績が会員名簿に記録されます（年間成績の元になります）。
  2. 「大会履歴」タブ → 現在の大会を履歴へ保存 — 今日の大会を記録として残します。
  3. ☰ → バックアップ — 控えファイルを1本保存。

ここまでやれば今日の分は完了です。次回の準備（全リセット）は、この続きでやっても、次回当日の朝にやっても構いません（第2章）。

クラウドを使う運用（結果をみんなで共有・別端末からも見られる）をする場合は、片付けの最初に ☁ クラウドへ送信（任意） を押します。ログインが必要なので、詳しくは第9章へ。使わなくても大会運営・印刷・報告書には一切影響しません。

第7章よくある「困った」— 名前の間違い・途中で帰る人など

実際の大会で起きやすいことと、その対処です。どれも参加者の行の ⋯ 編集 から行います。

① 名前を間違えて登録した（大会の途中でも直せます）

  1. ⋯ 編集 → ✏️ 名前を編集 を押し、正しい名前に直して OK
  2. 続けて確認画面が出ます。ふつうは この大会のみ修正 を選べばOK（会員名簿の方も直したいときだけ「会員マスタも更新する」）
似た画面に「別の人に差し替える」があります。これは本当に別人だったとき（登録した人と実際に指している人が違った）用です。名前の字の間違いなら「名前を編集」を使ってください。

② 途中で帰る人が出た（棄権）

⋯ 編集 → 棄権にする（以降の組み合わせから外す）。それまでの成績は残ったまま、次の回戦から組み合わせに入らなくなります。

③ 受付はしたが、1局も指さずに帰った人がいる

この場合は棄権ではなく 受付を取り消す（一覧から削除） を使ってください。1局も指していない人が受付に残っていると、回戦を確定するときに「次の参加者が対局に登録されていません：〇〇」という表示が出て先に進めないことがあります。この表示が出たら、その人を「受付を取り消す」で外せば進めます。

④ 組み合わせを手で変えたい

各対局カードの右下にある 変更 ボタンで、対戦相手の入れ替えができます。基本は自動の組み合わせのままで大丈夫です。手合いの都合でどうしても、というときだけ使ってください。

第8章トラブル復旧 — 保存の仕組みと元に戻す方法

保存は4種類ある（役割が違う）

種類何をしてくれるか
💾 自動保存入力のたびにこの端末の中へ自動保存。操作不要。ただし端末の故障には無力
バックアップ（JSONファイル）大会データをファイルとして保存。端末が壊れても別の端末で復元できるのはこれだけ
☁ クラウドへ送信（任意）確定結果をクラウドで共有。控えにもなるが、バックアップの代わりではない
📋 名簿に反映今日の参加者を会員名簿に記録する。大会データの控えではない

症状別の対処

症状対処
ブラウザが落ちた・タブを閉じてしまった開き直すだけ。自動保存されているので続きから再開できる
間違えてリセットしたリセット直後なら画面に出る「↩ 元に戻す」で1回分復旧できる。慌てて他の操作をする前に押す
端末が壊れた・電池切れ別の端末でアプリを開き、☰→バックアップ→バックアップから復元（ファイル選択）で、保存しておいた shogi_backup_….json を選ぶ
バックアップファイルが見つからない端末のダウンロードフォルダで「shogi_backup_」を探す（iPhoneは「ファイル」アプリ→ダウンロード）
「確定して次へ」が押せない未入力の卓が残っている。画面の「残り〇卓 未入力です」を見て、入力漏れの卓を探す
「次の参加者が対局に登録されていません」と出る1局も指していない人が受付に残っている。第7章③の「受付を取り消す」で外す
赤い帯「データが保存されません」シークレットモードで開いている。通常のブラウザで開き直す
どうしても分からなくなったら：無理に操作せず、その画面のまま連絡してください。自動保存が効いているので、触らなければ悪化しません。　連絡先：＿＿＿＿＿＿＿＿＿＿

第9章慣れてきたら（クラウド・ライブ配信など／任意）

ここから先は全部やらなくても大会は成立します。端末内だけの運用に慣れてから、1つずつ試してください。

  • ☁ クラウド送信 — 大会結果をクラウドに残し、みんなで共有。先に「会員名簿」タブの「☁ クラウド管理ページを開く」からログインが必要。大会が終わったら最終結果タブで ☁ クラウドへ送信（任意） を押すだけ。
  • 📱 スマホ星取表 — ヘッダのボタンで、同じ端末の別タブに星取表を全画面表示。会場のディスプレイに映す用。ネット不要。
  • 📡 ライブ配信 — 参加者が自分のスマホで順位・星取を見られるようにする機能。インターネット公開なので、表示名は既定の「姓＋番号のみ」のままにし、掲示物に公開する旨を明記すること。
  • 2台で分担 — A級とB級で入力端末を分けられます。受付タブの「▷ 2台で分担して入力するとき」から。1台運営なら不要。

これらの詳しい手順は、既存の「当日運営マニュアル（印刷版）」に書いてあります。

第10章練習の合格チェックリスト

自宅での練習で、次の項目を上から順に全部できたら合格です。本番はこの縮小版を人数分やるだけです。

  • アプリを開いて、5つのタブを一通り見た
  • 架空の名前で、Aクラス4名・Bクラス5名を手入力で登録した
  • Aクラスを「全員で1局目を開始」で始めた
  • Bクラス（奇数）を「部分開始」→「未手合いをまとめて1局目作成」で始めた（1名が待機になることを確認）
  • 勝った人のボタンを押して、押し直し（取り消し・変更）も試した
  • 「確定して次へ」で2回戦に進んだ
  • 誰か1人の名前を「⋯ 編集」→「名前を編集」で直した
  • 誰か1人を「棄権にする」で外した
  • 4回戦まで進めて、最終結果タブで順位表を見た
  • 「対戦成績を印刷 / PDF保存」でプレビューを出した
  • ☰ → バックアップで、ファイルを1本保存した
  • ☰ → 「大会データを全リセット」で練習データを消し、会員名簿が残っていることを確認した
おさらい：練習中に押さないのは 📋 参加者を名簿に反映 と ☁ クラウドへ送信（任意） の2つだけ。
