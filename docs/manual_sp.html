月例将棋大会 当日マニュアル（要点）

当日の流れの要点だけをまとめています。詳しい説明は印刷版マニュアルか、画面内の「？ ヘルプ」を見てください。上部タブ＝参加者登録／対局管理／最終結果／会員名簿／大会履歴。
1. 開始前（参加者登録タブ）
https://kazuo1970takahashi-sketch.github.io/shogi/
  1. クラウドを使うなら、先に「会員名簿」タブからログイン
  2. 「回戦数」を確認（既定4回戦・開始後は変更不可）
  3. 参加者を登録（氏名・会費区分・ふりがな）
2. 各回戦（対局管理タブ）
  1. 〇クラス全員で1局目を開始（来た人からならこのクラスを部分開始）
  2. 勝った人のボタンを押して勝者を入力
  3. ○回戦 確定して次へ
3. 参加者に見せる（任意）
  • 📱 スマホ星取表…同じ端末の別タブで星取表を全画面表示
  • 📡 ライブ配信…参加者のスマホで見せる。QRを掲示（表示名は既定「姓＋番号のみ」）
ライブ配信はインターネット公開です。掲示物に「氏名・成績を公開する」旨を明記。終わったら⏹ 配信を停止。
4. 終了後（最終結果タブ）
  1. 順位を確認
  2. ☁ クラウドへ送信で結果を残す・共有する
  3. 報告書を印刷 / PDF保存
  4. 📋 名簿を更新で参加者を会員名簿へ反映
5. 困ったとき
  • 端末が壊れた・誤ってリセットした：別端末でアプリを開き、バックアップ画面で直前の JSON を復元
  • JSON は端末のダウンロードフォルダに shogi_backup_… で保存されます
保存はふだん自動なので操作は不要です。端末事故が心配なら、節目でバックアップを押してJSONの控えを取れます（任意）。※クラウド送信はバックアップの代わりにはなりません。
