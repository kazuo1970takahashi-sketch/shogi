月例将棋大会 当日マニュアル

このマニュアルは事前準備・全体像・困ったときの指針です。細かなボタン操作は、画面内のヘルプ（？）や確認メッセージに従ってください。記載の例はすべて架空です。
1. 大会開始前
https://kazuo1970takahashi-sketch.github.io/shogi/
  • 参加者を登録する
  • 「JSONバックアップ保存」を押す
  • 「大会開始」を押す
2. 各ラウンド（毎回）
  • 「ペアリング生成」で組み合わせ確認
  • 対局実施 → 勝者を入力
  • 「ラウンド確定」を押す
  • 「JSONバックアップ保存」を押す
保存すると shogi_YYYYMMDD_HHMM.json がダウンロードされます。ファイルの存在を必ず確認してください。
3. 大会終了後
  • 「成績」タブで順位確認
  • 「JSONバックアップ保存」を押す（最終）
  • 印刷 または 報告書ダウンロード
報告書・印刷を出したら、日時／各対局の勝敗／参加人数が正しいか目視で確認してください。
4. 知っておくと困らない運用の考え方
来た人だけで始める
（部分開始・逐次手合）		 全員そろわなくても1局目を始められます。受付順に2人ずつ「1卓追加」、または今いる人を一気に「まとめて1局目作成」。後から来た人も同じ操作で足せて、すでにある対局・結果は変わりません。手合いがまだの人は「未割当」として表示されます。
奇数のときの待機 人数が奇数だと1名が待機になります（対局には入らず次を待つだけ）。待機は不戦勝ではありません（勝ち点は付きません）。次のラウンドで対局に戻ります。1局目はできるだけ偶数になるよう受付・手合いを調整するとスムーズです。
クラスを増やす
（C 以降）		 A・B 以外の組（C…）を必要に応じて追加・改名できます。A・B は削除できません。開始済み・参加者がいるクラスも削除できません（混乱防止）。
ふりがな 氏名にふりがなを表示でき、同姓や読みづらい名前の取り違えを防げます。登録後でも編集でき、空にするとふりがな表示は消えます。
支部マスタ・
過去大会の統合		 会員の元データです。当日は大きくいじらず、参加者登録の素材として使います。万一データが壊れても当日の大会運営は止まらない設計で、元データは保全されます。
履歴 過去大会の記録は「履歴」で閲覧できます。いま進行中の大会とは別ものです。履歴を見ても今の大会は変わりません。
5. トラブル時
ブラウザが落ちた 「読み込み」→ 直前の JSON を選択
端末が壊れた 別端末でアプリを開き同じ JSON を「読み込み」
JSON が見当たらない ダウンロードフォルダで「shogi_」で検索
ℹ️ 連絡先は別途ご確認ください。
