沼津支部 月例将棋大会 当日運営マニュアル

このマニュアルは事前準備・当日の流れ・困ったときの指針です。細かなボタン操作は画面内の「？ ヘルプ」や確認メッセージに従ってください。画面は上部に5つのタブ（参加者登録／対局管理／最終結果／会員名簿／大会履歴）があります。ヘッダの常時ボタンは📱 スマホ星取表と📋 名簿を更新の2つで、案内・ライブ配信・バックアップ・リセットは右端の☰メニュー内にあります。記載の例はすべて架空です。

1. 大会開始前（参加者登録タブ）

  • アプリを開く：https://kazuo1970takahashi-sketch.github.io/shogi/
  • クラウドを使う場合は先にログイン：「会員名簿」タブの☁ クラウド管理ページ（名簿編集・ログイン）を開くからログイン（送信・ライブ配信・名簿取得に必要）
  • 「回戦数（全クラス既定）」を確認（既定4回戦・開始後は変更不可）
  • 参加者を受付する：📋 名簿から受付（過去参加者から選ぶ）で名前をタップして受付（会費区分も引き継がれます）。名簿にない方は＋ 名簿にない新規の方（手入力）を開いて氏名・会費区分〔一般／中学生以下／女性〕・ふりがなを入力
  • 必要ならクラスを追加（C以降。A・Bは固定で削除不可）
保存はふだん自動なので操作は不要です。
「⚠ この端末ではデータが保存されません」の赤帯が出たら、シークレット（プライベート）を解除し通常ブラウザで開き直してください。

2. 対局を進める（対局管理タブ・毎回戦）

  • 「対局管理」タブへ移動し、クラスごとに〇クラス全員で1局目を開始（偶数のとき）
  • 来た人から始めるならこのクラスを部分開始（未割当者を表示） → 未割当者を選んで選択した参加者で1局目を追加作成、または未手合いをまとめて1局目作成
  • 対局を実施 → 勝った人のボタンを押す（もう一度押すと取り消し、相手側を押すと変更）
  • 全卓入力したら○回戦 確定して次へを押す
⚠️ 節目（大会開始／クラス完了／全終了）で控えを促す黄色い帯（バックアップする／あとで）が出たら、バックアップするを押すと安心です。バックアップすると shogi_backup_日付_時刻.json というファイルがダウンロードされます。
⚠️「組み合わせを再生成」すると入力済みの勝敗が消えることがあります。確認メッセージをよく読んでください。

3. 参加者・会場に成績を見せる（任意）

  • 📱 スマホ星取表（ヘッダのボタン）…同じ端末の別タブで星取表を全画面表示。会場ディスプレイやサブ画面向け（ネット不要・自動更新）
  • 📡 ライブ配信…参加者が自分のスマホで順位・星取を見られるよう公開。開始は最終結果タブ先頭の配信欄から（☰メニューの📡 ライブ配信でも配信欄へ移動できます）
ライブ配信の手順：最終結果タブの「📡 参加者向けライブ配信（任意）」で、①表示名を選ぶ（既定「姓＋番号のみ（おすすめ）」／「フルネーム」は告知・同意を決めた場合のみ）→ ②📡 ライブ配信を開始 → ③出てきたQRを印刷して会場に掲示。配信中は上部に「📡 配信中」バーが出るので、終わったら⏹ 配信を停止。
掲示物には「氏名・成績をインターネット公開する」旨の告知を必ず入れてください。

4. 大会終了後（最終結果タブ）

  • 「最終結果」タブで順位を確認（「順位の見方」ヘルプあり）
  • ☁ クラウドへ送信で結果を残す・共有する（最終）
  • 対戦成績を印刷 / PDF保存
  • 「大会報告書」を入力 →報告書を印刷 / PDF保存
  • ライブ配信していたら⏹ 配信を停止
  • （任意）念のため ☰メニューのバックアップでJSONの控えも取れます
  • 📋 名簿を更新で今日の参加者を会員名簿へ反映
ℹ️ 報告書・印刷を出したら、日時／各対局の勝敗／参加人数が正しいか目視で確認してください。両クラスまとめて見たいときは☁ 両級まとめて表示（統合レポート）が使えます。

5. 「保存」は4つある（覚えておく）

系統 何をする／注意点
💾 自動保存 入力するたびこの端末の中だけに自動保存。何もしなくてOK（端末の故障・データ消去には備えられません）。
☁ クラウドへ送信（主・任意） 確定結果をクラウドへ。みんなで共有でき、控えにもなります。ログインとネット接続が必要。押さなくても運営は続けられます。
バックアップ（☰メニュー内） 大会データをJSONファイルに保存／復元。端末事故から復旧できるのはこれだけ。ネット不要。ファイル名は shogi_backup_日付_時刻.json。
📋 名簿を更新 今日の参加者を会員名簿（支部マスタ）へ反映。大会データの控えではありません。
共有・控えはクラウド送信を主に。ただしクラウドはバックアップの代わりではありません。端末が壊れたときに元に戻せるのは「バックアップ」（JSON）だけです。両方こまめに取っておくと万全です。

6. 知っておくと困らない運用の考え方

細かい操作より「原則」を押さえておくと、当日の判断に迷いません。

項目 考え方・原則
来た人だけで始める（部分開始・逐次手合） 全員そろわなくても1局目を始められます。「このクラスを部分開始」→未割当者を選んで「選択した参加者で1局目を追加作成」、または「未手合いをまとめて1局目作成」で今いる人を一気に組みます。後から来た人も同じ操作で足せて、すでにある対局・結果は変わりません。
奇数のときの待機 人数が奇数だと1名が待機になります（対局には入らず次を待つだけ）。待機は不戦勝ではありません（勝ち点は付きません）。次の回戦で対局に戻ります。1回戦はできるだけ偶数になるよう受付・手合いを調整するとスムーズです。
途中で帰る人（棄権） 受付タブの参加者カードの⋯ 編集から棄権にする（以降の組み合わせから外す）を選ぶと、次の組み合わせから外れます。それまでの成績は残ります（同じ場所から復帰もできます）。
席を譲る（別の人に差し替え） 数合わせで入れた人の席に本来の参加者が来たなど、座る人が別の人に変わったときは、参加者カードの⋯ 編集→✏️ 名前を編集で新しい方の名前を入力し、別の人に差し替える（名簿から選ぶ）を選びます。これまでの対局結果ごと差し替え先の方の成績になり、元の方の名簿（氏名・ふりがな）は変わりません。名簿にない方へは「名簿にない新規の方として差し替え」が使えます。単なる誤字はこの大会のみ修正で直します（人は変わらないので差し替えは使いません）。
表示名とプライバシー（ライブ配信） ライブ配信はインターネット公開です。既定の表示名は「姓＋番号のみ」で氏名を勝手に公開しません。フルネーム公開は主催者が告知・同意運用を決めた場合のみ選んでください（未成年参加を前提とした設計）。
クラスを増やす（C 以降） A・B 以外の組（C…）を必要に応じて追加・改名できます。A・B は削除できません。開始済み・参加者がいるクラスも削除できません（混乱防止）。
ふりがな 氏名にふりがなを表示でき、順位表・星取表・報告書などでも取り違えを防げます。登録後でも編集でき、空にするとふりがな表示は消えます。
2台で分担する（A級・B級） 2台で入力を分けるときは、受付タブの「▷ 2台で分担して入力するとき」で、1台目で運営共通キー（4桁）を発行→2台目でそのキーを入力して「このキーに合わせる」。両方の送信が同じ1つの大会にまとまります（各台は自分の級だけ送るのがコツ）。1台運営なら操作は不要です。
会員名簿・クラウド名簿 会員の元データです。当日は大きくいじらず、参加者登録の素材として使います。「☁ クラウドから取得」で最新の名簿を取り込めます（ログイン時）。万一データが壊れても当日の運営は止まらない設計です。
履歴 過去大会は「大会履歴」タブで閲覧できます（端末内の記録＋「☁ クラウドの過去大会」）。いま進行中の大会とは別もので、見ても今の大会は変わりません。

7. トラブル時の復旧手順

状況 対処
ブラウザが落ちた・誤ってリセットした ☰メニューの「バックアップ」→「バックアップから復元（ファイル選択）」で直前の JSON を選ぶ（テキスト貼り付けでも可）
端末が壊れた・バッテリー切れ 別の端末でアプリを開き、同じ JSON を ☰メニューの「バックアップ」画面で復元（クラウド送信済みなら結果はクラウドにも残ります）
JSON ファイルが見当たらない ダウンロードフォルダ（iPhoneは「ファイル」→「ダウンロード」）で「shogi_backup_」を探す
クラウドに送れない ログインとネット接続を確認。送れなくても運営は続行でき、あとで再送信できます
ライブ配信が切れた 上部「📡 配信中」バーで状態を確認。必要なら再度「📡 ライブ配信を開始」
「⚠ 未保存の恐れ」が出た 自動保存の確認が取れなかった表示（必ずしも失敗ではない）。落ち着いて続行し、念のため「バックアップ」で控える
ℹ️ リセット操作（大会進行データをリセット／大会データを全リセット）は、ヘッダ右端の ☰メニュー内「危険な操作」にあります（誤タップ防止のため1段深く。「元に戻す」で1回分復旧できます）。連絡先は別途ご確認ください。
