## PAIRING-CARD-COMPACT-001: 対局カードを 182px → 147px にする

- **問題**: 作者「スクロールが延々と続く（ページが長い）」。対局管理は 30名2クラスで **12,905px（約17画面）**
  あり、その **42.3%（5,460px）が対局カード**（実測・375px・実 Chromium）。
- **カード182px の内訳**（実測）: **44px ヘッダ行**（★中身は「変更」ボタン1つだけ・左は全部余白）
  ＋4px ＋ **77px 対戦行** ＋8px ＋ **23px 理由ラベル行** ＋ 26px カードの padding/border。
- **修正2点**:
  ① **「変更」を理由ラベルの行の右端へ同居**させ、専用のヘッダ行を1本無くした。
  　 行の高さは `max(44, 23) = 44px` になり **−27px**（182 → 155px）。
  ② カードの余白を詰めた（`padding:12px→8px` / `margin-bottom:8px→6px`）。**−8px**。
  → **147px。ページは 12,905 → 11,799px（−9.0%）。** 375px の1画面に入るカードが 2.5枚 → 3枚。
- **★ 効かない・逆効果だった案（実測で捨てた）**: これらは Issue #942 に「やること」として
  書かれていたもので、cowork が測って撤回した。
  - **「変更」を対戦行の右端へ** … **186px と逆に伸びる**。対戦行の横の余りは 21px しかなく、
    ボタン（64px＋gap 8px）を入れると名前が折り返して対戦行が 77 → 129px になる
  - **勝敗数を名前の右へ**（列→行） … **223px**。同じ理由で総崩れ
  - 名前ボタンの `min-width` を 7.5em→5.5em … 高さは**不変**
  ★ **律速は高さではなく横幅だった。** 「行を消せば高さが減る」ではなく「入る場所へ移せば行が減る」。
- **★ 撤回した案（既存 pin が止めた）**: 名前ボタンの `min-height:2.9em→2.4em` は 17px 基準で
  **40.8px**＝タップ標的 44px を割る（`test_tap_target_dense_001.js` S5-2 が赤）。
  効きは −2px/枚しかなく、44px の保証と引き換えにする価値がないので**入れていない**。
- **不変**: 「変更」の `min-height:44px` / `min-width:64px` / id / bind / 文言 / confirm 導線（#737・§10.3）。
  文字サイズ（FONT-FLOOR-001 の床15px）。理由ラベルの中身と色。対戦行の並び。
- テスト: `test/e2e/pairing_card_compact_942.e2e.js`（実 Chromium・375px・30名2クラス＝19件）。
  ★ **高さは実ブラウザで実寸を読む**（#941 で「行を消せば減る」という見込みが 0px で外れた面）。
  C1 カード直下の行が2本＝専用ヘッダ行が無い ／ C2 カード平均 160px 以下（旧構成 182px を捕まえる網）／
  C3 「変更」は全カードで 44px 以上・id 不変 ／ C4 横あふれ 0 ／
  ★ C5 **理由ラベルが1つも無い場面でも「変更」が消えない**（旧実装は行ごと出し分けていたので、
  同居させたあとに出し分けが残ると「変更」が消える。`evaluatePairingQuality` を差し替えて実際に空にして測る）／
  ★ C6 余白は**カスケード解決後の実効値**で押さえる（C2 の上限では余白を戻す退行が素通りすることを変異で確認済み）。
  変異4本で赤を実測（ヘッダ行を戻す／`min-height` を落とす／ラベル空で行ごと消す／余白を戻す）。
  `test_tap_target_dense_001.js` S2 は「**変更ボタンが flow に居る**」へ書き直し（どの行に居るかが
  変わっても 44px 成立の条件は変わらない）＋「旧出し分けが残っていない」を追加。golden master 再生成。
