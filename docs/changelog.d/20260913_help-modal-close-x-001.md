## HELP-MODAL-CLOSE-X-001: ヘルプの「閉じる」が初期表示で見えない

- **問題**: 「？」ヘルプのカードは本文が画面の 85% を超えるとスクロールする作りで、「閉じる」はカードの一番下だけにあった。項目の多いヘルプ（クラウド送信・取得など）は iPhone だと「閉じる」が初期表示で隠れ、閉じ方が分からない（背景タップでも閉じるが案内は無い。2026-09-13 作者報告）。
