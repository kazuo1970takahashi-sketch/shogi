## FM-FIX-INPLACE-001: 「終わった対局」の「直す」で、その対局を上段へ飛ばさずその場で大きいカードに開く（#976）

- **問題**: FINISHED-MATCH-FOLD-001（#943）の「直す」は畳んだ 1 行を上段の大きいカードに戻していた。押した行が目の前（下段の一覧）から消えて画面の上（スクロールの外）に現れるため、操作の結果が操作した場所から見えなかった（作者指摘 2026-09-10「なんかわかりづらいな」）。
- **修正**: 「直す」で開いた対局は「終わった対局」の中の**その場**に、上段と同じ大きいカード（勝者ボタン・補助ラベル・理由ラベル・「変更」・同じ id）で出す。その場のカードで勝者を押し直してもその場に留まり、別の対局を操作したら従来どおり 1 行に畳まれる。上段で勝者を押した対局は従来どおり上段に残る（#943 の「直前に操作した 1 件」規則は不変）。「終わった対局（N）」の N にはその場のカードも数える。実装は「直前に操作した対局」の記憶をクラス別の値 1 つ `{owner, key, where}` にまとめ（key＝回戦＋顔ぶれは #943 のまま・where＝'top' | 'inplace'・owner＝`state.results[cls]` の配列そのもの＝復元・リセットで置き換わるので同じ回戦・同じ顔ぶれを復元しても古い記憶は効かない・#950 の dsSlot と同じ型）、`buildCurrentPairingsHtml` でカードの行き先を分岐しただけ。判定・保存ロジック・bind は無改変。
- テスト: `test/e2e/finished_match_fold_943.e2e.js`（F4 系を意図的に更新: その場に開く／上段に出ない／件数／押し直しで留まる／別の対局で畳まれる。SNAP を上段・その場・下段の 3 つに分けた。復元で古い記憶が効かないことも固定）。`disclosure_state_950.e2e.js` は無改変で緑。
