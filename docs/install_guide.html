将棋大会アプリを
「ホーム画面」に追加しよう

最初に一度だけ設定すれば、次からはアイコンを押すだけで開けます。

これをすると便利！
毎回リンクを探さなくてよくなります。スマホの画面に 将 のアイコンができて、ふつうのアプリと同じように一発で開けます。

iPhone Safari（サファリ）で開いている場合

※ iPhone は必ず Safari（標準の青いコンパスのアプリ）で開いてください。

  1. 将棋大会アプリのページを開きます。
    （役員から送られたリンク、またはこの運営サイトの「大会運営アプリを開く」を押す）
  2. 画面右下の •••（点が3つ）を押します。
  3. 出てきたメニューの中の 共有 を押します。
  4. ここが大事！ 出てきた画面を指で下のほうまでスクロールします。
    下のほうに ホーム画面に追加 があるので押します。
    （最初の画面には出ていません。必ず下までスクロールしてください）
  5. 右上の 追加 を押します。
完了！ ホーム画面に 将 のアイコンができます。次からはそれを押すだけ。

Android Chrome（クローム）で開いている場合

  1. 将棋大会アプリのページを開きます。
  2. 画面の右上にある⋮（点が縦に3つ）を押します。
  3. メニューの中の アプリをインストール または ホーム画面に追加 を押します。
  4. 確認が出たら インストール（または 追加）を押します。
完了！ ホーム画面に 将 のアイコンができます。次からはそれを押すだけ。
電波が無い会場でも使うには（初回だけ）
ホーム画面のアイコンを作ったら、一度インターネットにつないだ状態でアイコンから開いて、10秒ほど待ってください。 これでアプリが本体に保存され、次からは電波が無くてもアイコンから開けます。 （iPhone はアイコンのアプリと Safari が別管理のため、アイコンから一度開いておくのがコツです）
大事なお願い（とくに iPhone）
アプリを入れた直後は、これまでの名簿が「空」に見えることがあります。あわてず、大会を始める前にアイコンから開き、「マスタ」タブの 「☁ クラウドから取得」 を押すと名簿が出てきます（インターネットにつながっているとき）。
うまくいかないときは、支部役員（事務局）にこの画面を見せて相談してください。スマホの機種や設定で表示が少し違うことがあります。
